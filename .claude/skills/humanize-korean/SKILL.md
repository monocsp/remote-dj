# humanize-korean — AI 티 안 나는 한국어

한국어 글의 AI 티는 대부분 **영어 직역 구조**에서 나온다. 조사로 풀고, 능동·단정으로
쓰고, 어미와 문장 길이를 일부러 흐트러뜨리고, 뻔한 관용 맺음과 장식을 걷어내면 거의
사라진다. 아래를 적용하되, 의미·사실·고유명사는 절대 바꾸지 않는다.

## 1) 번역체·영어식 어순 (가장 큰 AI 티)

- "~에 대해 / ~에 대하여 / ~에 관하여" 남발 → 목적격 조사로. ("환경 문제에 대해 논의한다" → "환경 문제를 논의한다")
- "~을/를 통해" → "~로 / ~해서". ("API를 통해 가져온다" → "API로 가져온다")
- "~에 있어서" → "~에서 / ~할 때" 또는 삭제.
- "~을 가지고 있다"(have 직역) → "~이 있다 / ~하다". ("회의를 가졌다" → "회의를 했다")
- 이중 수동 "~되어진다 / 판단되어진다" → "~된다 / 판단한다".
- 수동태 남발("~에 의해 ~된다") → 주어를 사람·기관으로 세워 능동으로.
- 영어식 사물주어("이 연구는 ~을 보여준다") → "이 연구를 보면 ~을 알 수 있다".
- 복수 "-들" 남발(영어 -s 직역) → 대부분 삭제. ("사용자들이 버튼들을" → "사용자가 버튼을")
- 소유격 "-의" 사슬("회사의 제품의 품질") → 조사 생략·재구성.
- 진행형 "~하고 있다" 남용 → 단순 현재. ("증가하고 있다" → "증가한다")

## 2) 어미·리듬 (반복이 곧 AI 티)

- 같은 어미 행렬("~습니다 / ~할 수 있습니다 / ~다" 연속) → 어미와 문장 길이를 의도적으로 섞고, 짧은 문장과 긴 문장을 교차.
- 사실 서술에 "~할 수 있습니다" 반복 → 단정형으로. ("성능을 높일 수 있습니다" → "성능을 높입니다")
- 헤지 적층("~할 수 있을 것으로 보인다") → 한 겹만, 또는 단정.

## 3) 군더더기·관용구 (거의 전량 삭제)

- "결론적으로 / 종합하면 / 요컨대"로 마무리 열기 → 삭제(마지막 문단이 곧 결론).
- "도움이 되었기를 바랍니다 / 참고하시기 바랍니다" 식 맺음 → 삭제하거나 구체적 다음 행동으로.
- 빈 강조어 "매우 / 정말 / 굉장히" → 대부분 삭제, 필요하면 구체 수치로.
- 과장 형용사 "혁신적인 / 획기적인 / 압도적인" → 삭제 후 사실로.
- "~하는 작업을 수행한다 / 진행한다" → 동사 하나로. ("삭제하는 작업을 수행합니다" → "삭제합니다")
- "-적 / -성 / -화" 명사화 남발 → 동사·형용사로 풀기.

## 4) 문두 접속사

- 매 문장 앞 "또한 / 따라서 / 즉 / 나아가" 줄세우기 → 꼭 필요한 곳에만, 3연속 금지.
- 접속사 뒤 쉼표("따라서, / 그러나,") → 쉼표 빼기.

## 5) 마크다운·시각 장식

- 격식 있는 글에선 이모지 0개, 볼드 최소, 불릿·번호 남발 금지 — 가능하면 산문으로.
- 기계적 병렬 나열(모든 항목이 같은 품사·같은 길이) → 길이·구조를 흐트러뜨려 사람 손길을 남긴다.

## 6) 절대 보존

숫자·단위·날짜, 고유명사·인명·제품명, 따옴표 안 직접 인용, 법령·전문용어, 업계 표준
영어 약어(API, LLM 등)는 그대로 둔다. 장르(칼럼은 칼럼, 매뉴얼은 매뉴얼)를 바꾸지 않는다.

## 예시 (전 → 후)

- "본 API를 통해 인증 처리가 수행될 수 있으며, 결론적으로 매우 효율적이라고 할 수 있습니다."
  → "이 API로 사용자를 인증한다. 요청 한 번이면 끝나서 손이 덜 간다."
- "이 기능은 경험을 개선할 수 있습니다. 또한, 생산성을 향상시킬 수 있습니다. 따라서 매우 혁신적입니다."
  → "이 기능을 쓰면 화면이 한결 편해진다. 일하는 속도도 빨라진다. 이런 방식은 이번에 처음 넣어 봤다."
